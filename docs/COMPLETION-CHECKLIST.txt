VALIDATION LIMITS, not silently claimed complete:
- No representative production false-alert-per-hour study, unseen-ransomware-family evaluation, or guaranteed detection. Four roughly five-second benign controls do not establish an hourly production rate. Combined rules still miss slow/partial synthetic changes and alert on authorized encryption.
- Resource samples cover bounded whole-check/harness activity, not steady-state production overhead. CPU/GPU/system-wide accuracy or all-device performance is not claimed.
- Windows desktop was exercised; Linux/macOS execution and exhaustive browser/accessibility certification were not performed. The tested Compose accessibility tree did not expose internal app controls, so full screen-reader support is unverified.
- The memory fixture check uses AES sample-block validation, not authenticated file decryption. Live child-process RAM capture, arbitrary memory scanning, kernel drivers and system-wide pre-write prevention are explicitly optional future gates and are not implemented.
